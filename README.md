# Next Word Prediction using RNN

## Overview

This project focuses on **Next Word Prediction using Deep Learning and Recurrent Neural Networks (RNN)**.

The model learns patterns and relationships between words in a text dataset and predicts the **next possible word** based on the words provided as input.

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Natural Language Processing (NLP)
* Recurrent Neural Networks (RNN)

## Project Workflow

1. Load the text dataset.
2. Clean and preprocess the text.
3. Tokenize the text into words.
4. Create input sequences.
5. Prepare sequences for model training.
6. Build an RNN-based deep learning model.
7. Train the model on the text data.
8. Provide input text to the trained model.
9. Predict the next word.

## Model

The project uses a **Recurrent Neural Network (RNN)** to learn sequential patterns in text.

For example:

```text
Input:  "Artificial intelligence is"

Prediction: "powerful"
```

The model uses the previous words as context to predict the next word.
